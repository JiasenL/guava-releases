# Guava for Windows

Desktop video downloader with an integrated media browser.

Download the Windows x64 installer from [Releases](https://github.com/JiasenL/guava-releases/releases/latest).

Guava downloads future updates automatically. Choose **Restart and update** when ready; active media downloads must finish or be paused first. Older installations need the updater-enabled installer once.

This repository contains installers and update metadata. Application development is maintained separately in a private repository. macOS automatic updates are not included.

Windows installers are currently unsigned, so Windows may display an unknown-publisher warning.
